# Blind adjudication package (Stage 3)

Two independent LLM adjudicators will read **only** the files in this directory
that are marked evaluator-facing. The private mapping must never be handed to a
model.

## Files

| File | Audience | Contents |
|---|---|---|
| `adjudication_prompt.md` | evaluator | the protocol |
| `pilot_12_claims.jsonl` | evaluator | 12 claims, 3 per score stratum, disjoint from the 80 |
| `factscore_80_blind.jsonl` | evaluator | 80 claims, 20 per score stratum |
| `adjudication_schema.json` | evaluator | output schema |
| `source_manifest.jsonl` | both | one row per biography: title, URL, retrieval date, chars, sha256 |
| `selection_manifest.json` | both | sampling seed, strata, what is withheld |
| `private_id_mapping.json` | **private** | blind id → pid, claim index, frequency score, FActScore annotation |

`part4_40_blind.jsonl` is generated by `../build_part4_package.py` from
`cache/ext/clusters.jsonl` and `cache/ext/labels_wiki.jsonl`, restored from the
cluster on 2026-11-17. It holds 40 claims under two evidence conditions,
`first_3000` and `full`: 20 claims that the grounded labels call `contradicted`
at support 1.0, plus 20 mixed. The pair is deliberately redundant — it measures
whether the 3,000-character cap in `relabel.py` is what drives `absent`
verdicts, which is the confound the A4 audit raised.

## What the evaluator never sees

- the FActScore annotation (`Y`/`S`/`N`/`U`);
- the frequency score used by the baseline;
- the tie-break noise term;
- the previous LLM grounded labels;
- any prior judgment, hypothesis, or expected result.

Sampling depends only on the frequency-score stratum, never on the annotation.
The seed is fixed in `selection_manifest.json`.

## Suggested workflow

1. Give the evaluator `adjudication_prompt.md` and `pilot_12_claims.jsonl`
   (about 27 KB) in one message. Ask for JSONL only.
2. Check that every line validates against `adjudication_schema.json` and that
   every quote actually occurs in the corresponding `evidence_text`. Reachable
   quotes are the cheapest check that the model read the passage.
3. If the pilot adheres, run `factscore_80_blind.jsonl` (about 300 KB — use an
   API or a file-upload harness, not a chat paste).
4. Run the second model on the same 12 pilot claims **without** showing the first
   model's output, then on a stratified 20 of the 80.
5. Record for each run: model identifier as displayed, harness, date, decoding
   settings, and the raw response file.

## Known limitation carried into the data

The cached evidence is capped at 12,000 characters and was retrieved on
2026-11-08; per-article revision IDs were not stored, so `revision_id` is null.
Eight of the 25 test biographies have extracts under 2,000 characters, two of
them disambiguation pages. For those claims the evidence is thin by construction
and `unknown` is the expected correct answer.
